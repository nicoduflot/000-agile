# Roadmap – Médiathèque inter-communale

## Backbone (Activités principales) & fonctionnalités / epics

Le backbone est une transformation de la storymap qui permet d'écrire plus facilement la roadmap

| Activité utilisateur (Backbone) | Fonctionnalités / Epics | Livraison  |
|---------------------------------|-------------------------|------------|
| **Explorer le catalogue d’œuvres** | Catalogue des œuvres | V1 (MVP) – mars 2026 |
|                                 | Fiche détaillée d’une œuvre | V1 (MVP) |
|                                 | Affichage disponibilité | V1 (MVP) |
|                                 | Recherche / filtres dans le catalogue | T2 2026 |
|                                 | Alerte “œuvre disponible” | T2 2026 |
| **Gérer son compte utilisateur** | Création de compte (email, mot de passe) | V1 (MVP) |
|                                 | Connexion / déconnexion / mot de passe oublié | V1 (MVP) |
|                                 | Gestion minimale du profil (email, mot de passe) | V1 (MVP) |
|                                 | Gestion profil étendu (adresse, préférences, contact…) | T3 2026 |
| **Réserver des œuvres**         | Réservation en ligne d’une œuvre | V1 (MVP) |
|                                 | Historique des réservations | T2 2026 |
|                                 | Modification / annulation de réservation | T3 2026 |
| **Click & Collect**             | Outil interne de préparation des réservations (pour médiathèque) | T3 2026 |
|                                 | Notification de disponibilité & retrait prêt | T3 2026 |
| **Accès PMR / Procuration**     | Fonctionnalité de procuration pour retrait via mandataire | S1 2027 |
|                                 | Workflow retrait mandataire (site + logistique) | S1 2027 |
| **Administration / Gestion back-office** | Interface de gestion des réservations & disponibilités | T2 2026 |
|                                 | Outil de gestion du stock / inventaire | T3 2026 |
|                                 | Gestion du processus Click & Collect / retraits | T3 2026 |
| **Accès aux bornes en mairie**  | Interface borne pour réservation (depuis mairie) | S1 2027 |
|                                 | Synchronisation disponibilité en temps réel + retrait | S1 2027 |
| **Échanges entre habitants**    | Module d’échange / prêt entre particuliers (annonces, contact) | S1 2027 |
|                                 | Suivi des échanges (statut, disponibilité, historique) | S1 2027 |
