## Backlog Préliminaire

On commence a formaliser les besoins dans un backlog
On utlisera l'agilité et les termes suivants :

* Theme 
    >Le thème est un regroupement de stories.Utile pour définir des priorités, il >peut permettre, par exemple, de regrouper des stories pour affiner, définir ou  correspondre à l’objectif d’un sprint.
    >
    >Il peut aussi correspondre à un domaine fonctionnel qui permettra de faciliter la vision de l’avancement.
    >
    >Un thème peut être transverse à plusieurs features.
* Feature
    >La feature (fonctionnalité), est le service rendu à un niveau très global.
    * Epic
        >Regroupe plusieurs user stories autour d’un thème fonctionnel.
        >Une epic est une grosse user story qui nécessite d’être découpée, notamment si elle ne tient pas dans un sprint.
        >
        >Utile pour définir des priorités, il peut permettre, par exemple, de regrouper des stories pour affiner, définir ou correspondre à l’objectif d’un sprint.
        * User Story
            >Une user story est le niveau de granularité fonctionnel le plus fin.
            * Sous-Tâche
            >La tâche est une subdivision technique de la user story.
            >Elle peut permettre de diviser le travail à réaliser pour que plusieurs personnes puissent réaliser une user story.
    * Bug
    >Problème à corriger pour assurer la stabilité du produit.
    * Spike 
    >Exploration technique ou UX pour réduire les incertitudes.
    * Tâche technique
    >Élément non visible de l’utilisateur mais nécessaire au fonctionnement.
